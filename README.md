# Marketing homework — ENOT

Аудит доказательности текущего лендинга ENOT и новый messaging-brief для страницы интернет-эквайринга.

## Как смотреть проект

1. `SPEC.md` — аудитория, рамка и открытые вопросы.
2. `research/sources.md` — 7 открытых источников.
3. `research/facts.md` — 16 проверяемых утверждений.
4. `research/insights.md` — отдельно сформулированные выводы и гипотезы.
5. `research/claims-audit.md` — проверка рекламных обещаний.
6. `artifact/messaging-brief.md` — итоговый маркетинговый артефакт.
7. `COMPARISON.md` — сравнение наивного и итогового вариантов.

## Что сделано

- Исследование привязано к ENOT, его документации, требованиям, контактам и оферте.
- Официальные заявления отделены от факта наличия независимых отзывов.
- Каждый продуктовый факт брифа имеет F-ID.
- Сформирован первый экран, четыре смысловых блока и план A/B-проверки.
- Разобраны девять неподтверждённых или рискованных обещаний.

## Ограничения

Внутренние данные ENOT, CRM, аналитика, реальные тарифы отдельных мерчантов и SLA не предоставлены. Поэтому это исследовательский бриф, а не готовая к публикации юридически согласованная страница. Перед внедрением владелец проекта должен ответить на вопросы из `SPEC.md`, согласовать формулировки с legal/compliance и задать параметры эксперимента.

Проект опубликован в публичном GitHub-репозитории. Независимый аудит другой моделью остаётся отдельным шагом перед сдачей. В журнал внесены только реальные пользовательские промпты; фиктивные запросы не добавлялись.
