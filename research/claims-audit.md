# Проверка рекламных утверждений

| Утверждение | Проверка | Решение |
|---|---|---|
| «лучший платёжный сервис» | Сравнительного исследования нет. | Удалить. |
| «для любого онлайн-бизнеса» | Есть требования и запрещённые категории [F08-F09]. | Заменить точным описанием аудитории. |
| «подключение за пару минут» | Интеграция может быть быстрой, но до неё есть регистрация и модерация [F03]. | Не обещать общий срок; разделить подготовку и техническую интеграцию. |
| «самые низкие комиссии» | Есть только собственное «от 1%», ставка зависит от проекта [F06-F07]. | Указать зависимость и не сравнивать без данных конкурентов. |
| «моментальные выплаты» | Выбранные источники не подтверждают общий срок выплаты. | Удалить. |
| «безотказная поддержка 24/7» | Главная сообщает помощь 09:00-00:00 МСК, а не 24/7. | Заменить подтверждаемым графиком после проверки владельцем. |
| «увеличить конверсию» | Нет эксперимента или клиентской метрики. | Оставить только как гипотезу A/B-теста. |
| «любые способы оплаты по всему миру» | Подтверждены конкретные категории, доступность зависит от тарифов [F05, F10]. | Перечислять доступные конкретному мерчанту методы. |
| «гарантирует безопасность каждой транзакции» | Абсолютная гарантия не подтверждена. | Удалить; использовать только согласованные compliance-факты. |
